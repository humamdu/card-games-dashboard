# Card Games Dashboard

## Overview
System to manage card games results:
- Trex
- Tarneeb 41/61
- Konkan
- Kanasah

## Features
- Players management
- Teams per match
- Round-based scoring
- Leaderboard system
- Game engines per rule set

## Stack
- Laravel 11 + blade
- MySQL
- TailwindCSS

## Installation
composer install
npm install
php artisan migrate
npm run dev
php artisan serve
